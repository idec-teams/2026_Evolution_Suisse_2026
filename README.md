# Evolution Suisse 2026 | iDEC 2026 team wiki

Wiki repository of **Evolution Suisse 2026**, a team of students from ETH Zürich and the University of Zürich competing in the [International Directed Evolution Competition (iDEC)](https://idec.io) 2026.

**Project:** continuous directed evolution of QtEncapsulin nanocompartments for programmable mRNA and protein cargo loading, with survival coupled to how well the cell packages dCas9 and its guide RNA.

**Live wiki:** [idec-teams.github.io/2026_Evolution_Suisse_2026](https://idec-teams.github.io/2026_Evolution_Suisse_2026)

## Repository layout

```
docs/          Markdown content and images (docs/_authoring.md is the authoring reference)
theme/         Custom MkDocs theme: templates, CSS, JS, fonts, structure data
tools/         Build scripts for the structure figures and screenshots
mkdocs.yml     Site configuration and navigation
.github/       CI: strict build, external-dependency check, deploy
```

The site uses a bespoke theme rather than Material for MkDocs. The build is pure Python and has no runtime dependencies on third-party scripts, styles or fonts; CI fails if one appears. The figures are renderings of deposited structures (6NJ8, 5F9R, 1MSW) generated by `tools/structures/*.py` into `theme/data/*.json`. See `HANDOFF.md` before changing `theme/js/`.

## Build locally

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/mkdocs serve --watch theme
```

The site is served at `http://127.0.0.1:8000/2026_Evolution_Suisse_2026/`. `--watch theme` is needed for theme edits to reload. `mkdocs build --strict` turns warnings, such as broken links, into errors, as CI does.

## Contributing

- Push to `main`; CI builds the site and publishes it to GitHub Pages.
- Team photos: save a portrait (4:5, about 800 px wide, WebP) as `docs/img/team/<slug>.webp` and reference it from `docs/team/index.md`.
- Writing style: technical, concise; keep every number, citation and caveat.
