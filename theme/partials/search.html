{#- Search overlay. MkDocs' built-in search plugin ships search/{lunr,main,worker}.js into the site and appends search/main.js to extra_javascript automatically. main.js self-initialises and needs exactly two things from us: the `base_url` global (set in base.html ) and these two element ids. It writes results as

title

text

— MkDocs ships no CSS for them, so theme/css/search.css styles that markup. -#}
